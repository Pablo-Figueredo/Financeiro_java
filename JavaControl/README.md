# Controle de Conta Bancária

Este projeto é um desafio e uma atividade do meu curso de programação da Alura. Nele, desenvolvi um sistema simples para controlar uma conta bancária.

Pelo menu, é possível:

- Receber um valor na conta;
- Pagar (retirar) um valor;
- Visualizar o saldo;
- Sair do sistema.

O programa foi desenvolvido em Java e é executado pelo terminal.
